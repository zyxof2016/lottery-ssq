# 融合联合优化试验 v3

入口为「参考与融合 → 联合优化试验v3」，也可用 `pools?pane=reference&fusion=v3` 直接打开。v1、v2保留各自首次原档，原始参考5注和参考胆拖继续原样展示。默认仍为v2，v3明确标为独立试验，不把模型内分数变化宣传成真实中奖率提升。

## 本次实际改变

26131首次融合16红只覆盖01、31，漏10、19、26、33，蓝球15未入选。红池漏号无法靠同池组票修复；本轮同时改评分输入和完整票面目标。首次票面依据见 [26131复盘](cover16-review-2026-11-17.md)。

v2去掉了两层显式重号奖励，但仍把EWMA放在原专家混合与额外近期项中两次使用；蓝球取旧榜前2，单式按号码曝光均衡组票，胆拖直接截取红球排序前缀。它没有直接优化完整6＋1结果，而且参考5注的并集支持并没有被验证为概率。

v3使用项目已有的红球完整六红v2、蓝球去重v2，六个红球方向、五个蓝球方向各计一次。两组系数均只用23100及以前、预热30期后的2864期拟合，固定正则40，不因26131结果重调。红球通过6阶基本对称多项式在全部C(33,6)个完整集合上归一化，蓝球在16个结果上归一化。

```
P(S,b) = prod(w[S]) / e6(w[全部33红]) × P_blue(b)
目标 = 所选不同完整6＋1结果的模型质量之和
```

这是可分解红蓝模型，没有学习红蓝条件关联。参考ML目前没有足够同版本首次历史来校准贡献，v3把参考原5注作为5注10元的独立对照，不追加未经验证的10%并集奖励。5注与8注或10注预算不同，不能直接按总质量比较。

## 单式：全33红与16蓝的完整结果搜索

联合8注固定8个不同完整结果，共16元。按红球权重、蓝球概率分别降序，在六个递增红球索引和一个蓝球索引组成的状态图上作确定性最优前沿搜索。起点是最高六红和最高蓝；每次弹出前沿质量最大的完整结果，再加入合法的单坐标后继。同一状态只访问一次。

沿每条边概率不增，所有合法状态均可从起点到达，所以未访问状态的祖先始终在前沿中；弹出的前8个完整结果就是该可分解模型下全C(33,6)×16个结果的前8名。不预先截16红、不随机抽号，也不以单号曝光惩罚代替头奖目标。相同模型分数按号码确定性排序，同分次序不代表预测优势。

8注可能集中在1个蓝球，也可能只实际使用8个红球。页面显示真实用红、用蓝和完整票面，不将模型候选16红说成8注实际覆盖的16红。集中最高蓝优化的是完整结果质量，不等于提高“至少用到一次开奖号蓝”的概率。

## 胆拖：两种规格各10注20元

保留 **2胆5拖2蓝**、**3胆5拖1蓝**。在此正权重乘积分布下，候选并集里用较大权重替换未选中的较小权重不会降低任一展开项；在已选并集中，把较大权重从拖换为胆也不会降低展开质量。因此最大权重的前2或3个作胆，其后5个作拖、蓝球取概率前2或前1，是该模型在全33红范围的最优结构。这个前缀结论来自本模型的交换性质，不能推广到任意混合或条件概率模型。

所有胆码仍必须命中。完整展开分别为C(5,4)×2和C(5,3)×1，各10注，不按并集全中冒充单注六红。独立小规模穷举核对全部胆、拖、蓝组合，与交换解一致。

## 首次记录与页面

- GET `/api/reference-pools/fusion-v3?issue=26132` 只读，缺少历史v3时不补造；未封存当前期只返回预览。
- POST `/api/reference-pools/fusion-v3/freeze` 绑定目标期、输入摘要、显示票面摘要与模型源码摘要。陈旧预览、错期、越过截止、计算或写盘时钟倒退均拒绝。原子创建同名档案，重复请求返回首次版本。
- 原档为 `recommendations/fusion-v3/{issue}.json`，复盘为 `recommendations/reviews/{issue}/fusion-v3.json`。下载接口分别是 `/api/reference-pools/fusion-v3/archives/{issue}`、`/reviews/{issue}`，读取时检查原档摘要、模型、参考和v2父档、因果输入、完整票面及截止。
- 第一次启用前瞻后，原cycle及参考完成回调继续后续新期封存；原cycle负责逐注对奖，不增加timer。三个买法是独立选项，不合并成56元“同预算”。
- 手动交集可选择三个已封存v3票组的真实红蓝并集。预览或错期版本不加入原档目录，来源带版本、输入摘要和首次档案摘要。
- 修复复盘页加载档案时清空融合版本参数的问题，v1、v2、v3链接与切期均保留显式选择。v3红蓝文字颜色与v2保持同等对比度。

211项Rust测试通过，另有三套Node测试及隔离浏览器验收。发布先只读核对42个既有接口、180份运行文件和原reference环境，再独立为当前26132首次启用v3，核验仅新增一份正式原档、0期已开奖／1期待开、旧档不变及线上手机页面。隔离测试档案不上传生产。

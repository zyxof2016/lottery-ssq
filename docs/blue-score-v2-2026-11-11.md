# 蓝球评分逻辑v2

数据截至26129（2026-11-10），训练固定截止23100。计算、系数、求解证书、16蓝排序和各窗口完整结果见 [计算数据](blue-score-v2-2026-11-11.json)。

## 原逻辑的结构问题

原蓝榜先分别累计六个专家对数评分，再softmax加50%等权收缩，所以每个专家至少保留1/12≈8.33%权重。即使某个专家无效，也不能归零。

遗漏分数是`gap+1`，热度分数是`1/(gap+1)`。取对数并去掉各号共同的归一化常数后，两者严格互为相反方向，不是两份独立证据。反重号是在历史频率上把上期蓝球乘0.25，直接同时混合频率与反重号会再次使用相同频率信息。

26129中奖蓝05在原榜第14，六个专家内部均未入前2，删除任一专家仍排13或15。不能只靠改变配蓝轮转修复这个评分问题，也不能按本期05挑一个新权重。

## 新算法

新增冻结文件`blue_model_v2.rs`，完整蓝球概率模型为：

`P(b)=softmax_b(θ·x(b))`。

只保留五个去精确冗余后的对数轴，各轴按当期16蓝居中：历史频率、近期EWMA、遗漏间隔、反重号相对频率的修正、转移矩阵。遗漏轴使用`(log(overdue)-log(hot))/2`，反重号轴使用`log(anti_repeat)-log(frequency)`。

直接联合拟合中奖蓝球的归一化对数似然，系数可以为0或负数，不强制保留弱专家，不为号码身份增加单独参数。全部系数为0时回到均匀16蓝，而不是人为挑出某两个号码作为均匀预测优势。

固定正则强度40，不扫描温度、正则、种子或按近期命中挑模型。惩罚为：

`40/2 × [(θ_frequency−θ_previous)^2 + θ_previous^2 + θ_ewma^2 + θ_gap^2/2 + θ_markov^2]`。

这个五轴模型与最初预先固定的“六个原对数专家、每系数相同ridge40”完全等价：令原六系数为`[θ_frequency−θ_previous, θ_ewma, θ_gap/2, −θ_gap/2, θ_previous, θ_markov]`。删除遗漏／热度的精确零方向不会改变预测或先验；没有根据留出效果额外挑选五轴正则方案。独立Python六轴实现与Rust五轴模型的系数变换、完整评分及各窗命中逐值一致。

训练为04092–23100共2864条因果特征记录，前30条专家记录仅热身。之后系数冻结，只使用当期开奖之前的数据更新特征。牛顿法用Cholesky解线性系统、Armijo回溯，标准化梯度阈值1e−10；未收敛拒绝输出。正则矩阵最小特征值`(3−√5)/2`，给出训练目标剩余差距上界。当前3步收敛，标准化梯度约6.83e−12，目标差距上界约2.04e−17；这只证明训练求解充分，不证明预测有效。

拟合系数约为：频率−0.086783、EWMA−0.013756、间隔−0.027155、上期蓝球修正−0.051069、转移−0.009701。反向系数是固定训练窗得到的方向，不是将“冷号必出”写成规则。

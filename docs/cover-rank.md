# 全覆盖排序试验

这条排序只回答一个问题：能不能把“盖住全部 6 个开奖红球所需的最靠后名次”在开奖前拉短。它不输出中奖概率，不生成票面，也不改已封存方案。

## 损失和训练

每一期对每个开奖红球，计算它相对 27 个未开出红球的平均 softplus，再对 6 个开奖红球做 log-sum-exp。落后的号码权重大。系数的 L2 惩罚是 0.05，事先写定，没有在确认窗上搜索。

特征沿用红球评分 v2 的 6 条居中对数轴：长期频率、指数近期、间隔、上期共现、区间、上期重号。遗漏和热度仍只保留一个方向。样本是专家暖机 30 期之后、期号不晚于 23100 的 2864 期。牛顿法 2 步收敛，梯度约 5.6×10⁻¹¹。六个系数的绝对值都小于 0.01，得分几乎拉不开号码。

## 确认窗

25111–26115 共 156 期，排序只用该期以前的专家特征。

| 对照 | 平均盖住名次 |
| --- | ---: |
| 全覆盖排序 | 29.30 |
| 协议加权融合 | 28.99 |
| 均匀随机顺序的期望 | 29.14 |

相对协议加权融合少 −0.31 个名次，相对均匀期望少 −0.16 个名次。正数才表示全覆盖更靠前。预先要求这两项都至少为 1。前 78 期相对融合是 +0.05，后 78 期是 −0.67。门槛没有达到。

因此 `clears_predeclared_mean_gate` 为 false，`replaces_weighted` 为 false，`rewrites_archives` 为 false。页面把结果写在试验行和顶部说明里。推荐排序仍是协议加权融合，冻结号码池保持原档。

同一确认窗里，现有各条排序的平均盖住名次大约在 28.5 到 29.6 之间。均匀对照的某一固定种子可以落在这个区间的一侧，那是这一串种子的结果，不是均匀期望本身。没有一条达到少用 1 个名次的门槛。

# 融合覆盖试验 v4（2026-11-19）

入口为「参考与融合 → 融合覆盖试验v4」，也可用 `pools?pane=reference&fusion=v4` 直接打开。v1、v2、v3 保留各自首次原档；默认仍为 v2，v4 明确标为独立试验，不替换任何已封存票面。

## 本轮定位的两个问题

1. **v2 评分层残留 EWMA 双重计权。** v2 修复了显式重号的两层叠加，但公式 `0.9×(2/3×N + 1/3×EWMA) + 0.1×参考支持` 中，N 本身已含 EWMA 专家（experts[1]），EWMA 实际被计两次，额外权重 0.30。
2. **v3 搜索层目标与中奖结构脱节。** 最大化可分解模型质量的最优前沿把 8 注挤成几乎相同的票面：26132 实际只用 8 红 1 蓝，均匀常规奖覆盖 7.87%，低于 v2 同预算的 15.83%；而模型确认窗完整 6＋1 对数评分仍低于均匀（−0.004151）。集中投注只放大方差，不产生已验证的优势。

## v4 的实际改变

评分（冻结在 `fusion_model_v4.rs`）：

```
N   = 六专家按原相对权重归一化融合（显式重号权重0，EWMA只在此计一次）
v4  = 0.9×N + 0.1×参考并集支持
```

额外 EWMA 项移除（0.30→0）。10% 参考支持作为 v2 遗留投票保留，仍明确标为未校准；v3 把参考当对照的做法是另一条独立试验，不在本版合并。红球权重沿用协议在 25111 前冻结的拟合。蓝球改用 23100 及以前拟合、固定正则 40 的去重蓝球 v2 分布（与 v3 同组件），提供可计算的概率。

组票（8 注 16 元，只试验单式；v2、v3 胆拖保持各自原档）：

1. 红球取 v4 评分前 16。在全部 C(16,6)=8008 个组合上，先用既有均衡模板给出每红恰 3 次的可行票组，再做**确定性成对交换**：两注之间各换一个红球，曝光不变、票面不重复，仅接受严格提高模型质量和的交换，固定扫描顺序，最多 64 轮。起点可行、改进单调，不会陷入无解。
2. 蓝球取冻结蓝分布前 8，每蓝恰 1 注；红球集合按质量降序与蓝球概率降序同序配对（重排不等式最优）。
3. 结构性覆盖保证：8 个不同蓝球无条件覆盖 8×C(33,6) 个完整开奖结果，均匀常规奖覆盖 ≥50%，高于 v2 同预算票组的上界（2×C(33,6)+14×8×5428 ≈ 15.94%）；红球并集恰为 16，一等奖覆盖仍为 8 个不同完整结果。
4. 证书：池内无约束前 8 质量和为上界，报告实际红球质量与绝对差距；另报全 33 红 16 蓝无约束联合最优（v3 式前沿）作参考。不宣称池内全局最优，更不宣称真实预测优势。

## 限制

模型本身仍未证明优于均匀；v4 提高的是均匀开奖下的覆盖结构，不是中奖概率或回本能力。8 蓝使「至少中一次蓝」的机会为 8/16，但每蓝只有 1 注，更常中小奖不等于回本能力提高。参考支持未校准、蓝球组件冻结在 23100、交换搜索为启发式（有上界证书），均如实留档。后续算法变更须新增版本，不得编辑 v4 模型使已存档无法重算。

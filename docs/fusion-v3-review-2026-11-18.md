## 计算与入口

「参考与融合 → 联合优化试验v3 → 同预算 v3／v2 票面对照」随所选买法展示实际用号、常规奖覆盖及逐注复盘指标。GET `/api/reference-pools/fusion-v3?issue=26132` 的新增 `same_budget_comparison` 字段包含计数分子、统一分母及同一期 v2 父档摘要。待开奖入口仍可查看票面覆盖，实绩保持空值。

每个已用蓝球覆盖全部 C(33,6) 种红球结果，因为任何一注中蓝即获常规奖。对于其余蓝球，只计至少与一注票面重合 4 红的红球结果。逐注枚举 4、5、6 红重合的结果并去重后计入常规奖分子。一等奖分子等于不同完整 6＋1 票面的数量。特别奖单列待核，常规奖覆盖率衡量至少一次常规中奖，无法由此推算回本率。

v3 每次读取仍核验两级父档、输入历史、首次票面及对奖边界。服务按输入历史和两个父档的摘要复用最多 16 份模型重建结果，当前期在真实样本列表中复用同一次核验。手动封存直接核对提交的票面与模型摘要，避免为封存重复计算整个历史报告。已存原档、复盘 JSON 及模型源码摘要沿用原值。
